# 考研 C++ 刷题记录

这是我为以后考研复习整理的 C++ 数据结构与算法刷题记录，主要保存题目代码、解题思路和阶段性练习成果。

## 目录

- `luogu/`：洛谷题目练习代码
- `.vscode/`：本地 VS Code 编译和调试配置

## 记录目标

- 巩固 C++ 基础语法和常用 STL
- 练习数组、字符串、链表、栈、队列、树、图等数据结构
- 掌握排序、查找、递归、动态规划、贪心等常见算法
- 为之后的考研数据结构与算法复习积累代码和错题记录

## 编译运行

代码以单个题目文件为单位编译运行。例如：

```bash
g++ luogu/B2001.cpp -std=c++17 -O2 -o B2001
./B2001
```

不同题目可能需要根据题目要求调整标准版本或输入输出方式。

## 说明

本仓库会随着刷题进度持续更新，代码以学习记录为主。后续会逐步补充解题思路、复杂度分析和错题总结。
